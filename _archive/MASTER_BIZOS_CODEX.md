## 🛡️ 1. THE VISION: WHAT IS BIZOS?

To eliminate the gap between **Strategy** and **Execution**. In BizOS, the person who thinks (The CEO) and the system that executes (Arkle) are perfectly synced. We are building a future where a business can run itself with 90% autonomy.

## 🧠 2. ARKLE & THE ARKLE BRAIN

**Arkle** is the cognitive core of BizOS. It is not a chatbot; it is a **Digital Co-Founder**.

- **Arkle Brain:** The central memory repository. It understands your business's legal structure, sales patterns, customer behavior, and future goals.
- **Cognitive Memory:** Arkle remembers your preferences, past decisions, and strategic pivots.
- **Autonomous Execution:** Arkle doesn't just "suggest"; it "does". In **Agent Mode**, Arkle takes over the keyboard and mouse of the digital world to send WhatsApps, file GST, or update inventory.

## 🖥️ 3. BIZDESK: THE OPERATIONAL COMMAND CENTER

**BizDesk** is the primary interface of the OS. It is the cockpit from which the entire enterprise is piloted.

### The Concept

## 📊 7. THE MODEL MATRIX & CREDIT ECONOMY
BizOS uses a multi-model orchestration system to balance intelligence and cost.

### Model Hierarchy (Based on Arkle Neural Core)

| Tier | Integrated Model | Best For... | Credit Burn |
| :--- | :--- | :--- | :--- |
| **Arkle Titan** | **GPT-5.1-Codex-Max** / GPT-5.4 | High-level strategy, Complex Coding, Legal Drafting, System Architecture. | **15 Credits** per task |
| **Arkle Pulse** | **GPT-5.3-Codex** / GPT-5.2 | CRM Management, WhatsApp Flow, Email Drafting, Live Consultations. | **3 Credits** per task |
| **Arkle Neural** | **GPT-5.4-Mini** / GPT-5.1-Codex-Mini | Data entry, Status updates, Notification triggers, Log maintenance. | **0.5 Credits** per task |

### Operational Logic
- **Precision Tasks:** Arkle automatically switches to **Titan** (Max) for high-stakes business decisions.
- **Autonomous Loops:** Bulk background tasks use the **Neural** (Mini) engine to save 90% in operating costs.
- **Human Sync:** Manual chats generally run on **Pulse** for a balance of speed and wit.

## 🛠️ 8. TECHNICAL ARCHITECTURE & FILE MAPPING

This section serves as a direct navigation guide for the development system.

### 📂 Core Directories
- `/app/os`: The heart of the Operating System.
- `/components/os`: Individual functional "Nodes" or "Tabs".
- `/lib`: State management, API clients, and shared utilities.

### 📍 Key File Addresses
| Feature / Page | File Path | Responsible For... |
| :--- | :--- | :--- |
| **Main OS Controller** | `app/os/page.tsx` | Main navigation, tab switching, and shell UI. |
| **Arkle Brain (Home)** | `components/os/HomeTab.tsx` | Central chat interface, Agent mode, and Spotlight. |
| **Business Vault** | `components/os/CompanyTab.tsx` | Documents, Incorporation, and Business Identity. |
| **GST & Compliance** | `components/os/GSTTab.tsx` | GST filing dashboard, reports, and tax status. |
| **Banking & Finance** | `components/os/BankingTab.tsx` | Integrated banking ledger and payouts. |
| **LaunchPad Hub** | `components/os/LaunchPadTab.tsx` | Startup onboarding and new project initiation. |
| **Services Marketplace** | `components/os/StartupStoreTab.tsx` | Catalog of business services and add-ons. |
| **Global Market** | `components/os/GlobalTab.tsx` | Export/Import logistics and international trade. |
| **Sales & CRM** | `components/os/WorkspaceOS.tsx` | Lead management and pipeline automation. |
| **State Management** | `lib/useBizStore.ts` | Global store for messages, tasks, and UI state. |

### ⚡ Operational Shortcuts (For Developer)
- **Modifying Chat Box:** Go to `components/os/HomeTab.tsx`.
- **Adding New Tab:** Add route in `app/os/page.tsx` and component in `components/os/`.
- **Global Stylings:** Check `app/globals.css`.
- **Memory/Context Sync:** Update `lib/useBizStore.ts`.
